## Overview

An AI-powered CRM automation built with n8n that analyzes incoming lead information, evaluates lead quality, updates CRM records, and alerts sales teams about high-value opportunities.

The workflow helps businesses maintain an organized CRM while reducing manual data entry and improving lead management.

---

## Features

- AI-powered lead qualification
- CRM record updates
- Lead scoring
- Opportunity prioritization
- Follow-up recommendations
- Google Sheets integration
- Gmail notifications
- Structured JSON output

---

## Tech Stack
